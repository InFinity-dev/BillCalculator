요금 조회 설정

전기요금 및 수도요금 조회를 위한 웹사이트 URL을 설정하세요. 계산기 페이지에서 빠르게 접근할 수 있습니다.

예: 한국전력공사 요금 조회 페이지 URL
예: 지역 상수도사업소 요금 조회 페이지 URL
주택 전체에 적용되는 수도 고객번호입니다. 계산기 페이지에서 참조용으로 표시됩니다.

사용 방법

  • 계산기 페이지에서 "요금 조회" 버튼을 클릭하면 여기서 설정한 URL이 새 창으로 열립니다.
  • 수도 고객번호는 수도요금 계산 시 참조용으로 표시됩니다.
  • URL을 비워두면 해당 버튼이 표시되지 않습니다.

백업 복원

안전하게 묶은 범위 중 하나를 골라 복원합니다. 선택한 묶음은 백업 내용으로 완전 교체되며 행 단위로 병합하지 않습니다.

이력과 세대의 식별 정보가 맞지 않으면 복원이 자동으로 차단됩니다.

복원 전 확인

데이터현재복원 후
선택한 묶음에서 백업 파일에 없는 현재 데이터는 유지되지 않습니다. 적용 직전에 현재 DB를 자동 백업하며, 복원은 전체 성공 또는 전체 취소로 처리됩니다.

최근 자동 복원 지점

삭제·덮어쓰기·전체 복원 직전의 상태를 선택해 되돌립니다. 이 작업도 병합이 아닌 전체 교체입니다.
